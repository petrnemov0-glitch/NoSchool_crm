# NoSchool CRM — v0.1 (MVP)

CRM для репетитора: сегодняшний день, ученики, расписание, проведение занятий,
финансы и статистика. Progressive Web App — устанавливается на экран «Домой»
на iPhone и работает без App Store.

## Стек и почему он выбран

- **Vanilla HTML/CSS/JS, без сборки и фреймворков.**
  Для MVP с одним пользователем (репетитором) это самый быстрый путь к рабочему
  продукту: ноль зависимостей, ноль конфигурации сборки, файлы можно открыть
  и захостить где угодно за пять минут.
- **localStorage как хранилище данных.**
  Надёжно, работает офлайн, не требует сервера и бэкенда на этом этапе.
  Все данные (ученики, занятия, расходы) хранятся в браузере устройства.
- **Service Worker + Web App Manifest.**
  Даёт настоящую установку на экран «Домой» на iPhone, автономный запуск без
  адресной строки Safari и базовую офлайн-работу (кэш статики).

## Почему это НЕ ограничивает масштабирование

Архитектура отделяет данные (`state.students`, `state.lessons`, `state.expenses`)
от отображения. Когда понадобится несколько преподавателей / онлайн-школа:

1. Слой `loadArray()/saveArray()/persist()` в `app.js` меняется на вызовы к
   реальному API (например, Supabase, Firebase или собственный backend на
   Node/Postgres) — остальной код (рендер, экраны, логика занятий) не трогаем.
2. В модели данных уже заложены отдельные сущности `Student`, `Lesson`,
   `Expense` с понятными полями — это прямой путь к таблицам в реальной БД.
3. Этапы 2–4 (AI-отчёты, AI-аналитика, голосовой ввод) подключаются как
   дополнительные вызовы к API поверх существующих данных о занятиях —
   структура `lesson.homework`, `lesson.comment`, `lesson.status` уже готова
   быть источником для таких запросов.

## Важное ограничение текущей версии (честно)

Я собрал и протестировал этот проект как обычный статический сайт — такой
код нельзя "запустить" прямо в чате Claude как полноценный instalable PWA,
потому что для настоящей установки на экран «Домой» с офлайн-работой сайту
нужен собственный домен (HTTPS), а не песочница чата. Поэтому ниже — 3 простых
варианта разместить сайт за 2–5 минут, после чего установка на iPhone будет
работать по-настоящему.

## Как разместить сайт (выберите один способ)

### Вариант A — Netlify Drop (проще всего, без аккаунта на старте)
1. Откройте https://app.netlify.com/drop
2. Перетащите папку `noschool-crm` целиком в окно браузера.
3. Через несколько секунд получите ссылку вида `https://xxxx.netlify.app`.

### Вариант B — Vercel
1. Установите Vercel CLI: `npm i -g vercel`
2. В папке проекта выполните `vercel --prod`
3. Следуйте подсказкам — получите публичную ссылку.

### Вариант C — GitHub Pages
1. Создайте репозиторий на GitHub и загрузите туда содержимое папки `noschool-crm`.
2. В настройках репозитория → Pages → Source: `main` / `root`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Установка на iPhone (после публикации)

1. Откройте полученную ссылку в **Safari** на iPhone (обязательно Safari, не Chrome).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран “Домой”»**.
4. Готово — иконка NoSchool появится на главном экране и будет открываться
   как отдельное приложение, без адресной строки браузера.

```

```

## Данные и бэкап

Все данные хранятся в localStorage браузера **на конкретном устройстве**.
Это значит:
- при чистке данных браузера/переустановке — данные удалятся;
- данные не синхронизируются между iPhone репетитора и, например, ноутбуком.

Для реального ежедневного использования на следующем этапе рекомендуется
подключить облачное хранилище (Supabase — быстрее всего с этим стеком),
чтобы данные сохранялись на сервере и открывались с любого устройства.
Скажите, когда будете готовы — подключим.

## Реализованный функционал v0.1

- Главная: доход за сегодня, кол-во занятий сегодня, неоплаченные, ближайшее занятие
- Ученики: карточка, история занятий, домашние задания, долг/заработок, статус
- Расписание: неделя/день, добавление, редактирование, перенос
- Проведение занятия: ученик → статус → детали → сохранение (3 шага)
- Финансы: доходы/расходы, баланс, фильтры день/неделя/месяц
- Статистика: доход, занятия, средний чек, отмены, переносы, топ-ученик, динамика
